# Decision Intelligence AI Skill

A reusable AI decision-making skill for business, entrepreneurship,
marketing, sales, CRM, product development, ROI, risk analysis,
productivity, automation, and low-cost validation.

## What This Skill Does

This skill helps AI agents answer an important question:

> **Should we do it, and what is the lowest-risk way to proceed?**

Instead of jumping directly to execution, the skill evaluates:

Goal
→ Options
→ Cost
→ Benefit
→ Risk
→ Evidence
→ Uncertainty
→ Reversibility
→ ROI
→ Lowest-Cost Test
→ KPI
→ Next Action
→ Review

---

## Core Philosophy

- Validate before scaling
- Measure before assuming
- Protect downside
- Preserve upside
- Prefer evidence over intuition
- Prefer profit over vanity metrics
- Prefer reversible decisions under uncertainty
- Prefer actions that generate new information
